# wgo vs kgo simulation report

_Generated by `make simulation`. Non-deterministic snapshot: latencies are real wall-clock, so the exact numbers vary between runs._

- Cluster: 50 brokers / 50 partitions (1:1)
- Warmup 30s, observed 1m0s, event spacing 500ms, app-request timeout 5s
- **Event**: one simulated application write, issued every 500ms. Each event fans out one Produce record per partition (50 records/event, one per broker since partitions and brokers are 1:1) and is recorded as a single success/failure once every partition's record has settled or the 5s app-request timeout has elapsed.
